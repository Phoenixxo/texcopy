# Code of Conduct

I want texcopy to be a friendly place to ask questions, report bugs and contribute, whatever your experience or background.

**Be kind and assume good faith.** Disagree with ideas, not people. Give feedback you'd be glad to get yourself. Questions from newcomers are welcome. There aren't any stupid ones.

**Not ok:** harassment, insults, personal attacks, discriminatory language or jokes, sharing someone's private information, sexual attention or imagery, or wrecking a discussion on purpose.

**Where this applies:** the repository, its issues, pull requests and discussions, and anywhere someone is representing the project.

**If something goes wrong:** report it privately through GitHub (a private [security advisory](https://github.com/Phoenixxo/texcopy/security/advisories/new), or a message to me). Reports stay confidential. I may edit or remove comments, lock threads, and ban people who break these rules.

This is a short version in the spirit of the [Contributor Covenant](https://www.contributor-covenant.org), which is worth reading if you want the longer one.
