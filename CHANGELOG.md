# Changelog

Everything notable gets listed here. The format follows [Keep a Changelog](https://keepachangelog.com/en/1.1.0/) and the project uses [Semantic Versioning](https://semver.org/).

## [Unreleased]

### Added
- The window says "Copied to the clipboard" under the output after it copies. A new read always copies again, and text that hasn't changed isn't copied twice.
- `texcopy --uninstall` removes the models, the `llama-server` helper and the saved settings texcopy downloaded. `--dry-run` only lists them and `--yes` skips the question. On Linux, `install.sh --remove --purge` does it before removing the program.
- Human and exact output modes. `--mode human|exact` (or `TEXCOPY_MODE`) on the command line and a **mode** choice in the window, remembered between runs. `--raw` still works and means exact.
- `TEXCOPY_CONFIG_DIR` moves the folder where the window keeps its settings.

### Changed
- Human mode cleans more: spacing macros at the start and end of a formula (the small model reads an equation number as a run of `\qquad`), braces around cells in `aligned`, `array`, `gathered` and similar environments, `{}=` after an `&`, and `\;` or `\:` between plain symbols.
- The vision engine's math gets the same cleanup, so human mode looks the same whichever engine read the picture.
- The window is wider so the mode buttons fit on one row.

## [0.1.0] - 2026-10-11

First release.

### Added
- Read an image of LaTeX-rendered content and put its LaTeX on the clipboard: single formulas, sentences with inline math, numbered and unnumbered display equations, lists, headings and tables.
- A small window (a Capture button, `wrap` and `engine` options, the output text) and a `texcopy` command with JSON output.
- Two engines: a 118 MB formula model that runs in the program, and an optional vision model (OvisOCR2 through a local `llama-server`) with a guided, checksum-verified download.
- The window loads the vision engine while you drag the box, and unloads it when it's idle.
- Region selection through the OS's own tool (macOS `screencapture`, the common Linux screenshot tools) or texcopy's built-in overlay.
- Downloads for macOS (`.app`), Windows (a zip with a launcher that has no console) and Linux (a tarball with an installer), built by a release workflow.
- A benchmark that re-renders the output and compares it with the original (`tools/bench.py`).
- A seeded case generator written in Rust (`tools/gen`) that makes benchmark pictures with real LaTeX tools, and `texcopy --batch` to read many images with one loaded engine.
- Downloads include a license notices file, generated by `tools/third_party_licenses.py`.

### Known issues
- The output will be wrong or badly formed in plenty of cases, so proofread it. [docs/BENCHMARKS.md](docs/BENCHMARKS.md#where-it-gets-things-wrong) lists the kinds I know about, and issues and pull requests are welcome.
- I've only run it by hand on macOS (Apple Silicon). The Windows and Linux builds are built and tested by CI but haven't been tried on real machines yet.
- Styling that isn't part of the content (bold, italic, vertical table rules) doesn't come back.
